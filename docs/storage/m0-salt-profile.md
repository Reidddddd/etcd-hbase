# M0 公开盐 profile 候选

本文记录公开工程验证使用的默认盐候选。目标环境的盐算法、字节编码、桶数、预分区边界和校验样例仍等待 B01；本文不把公开候选声明为目标表格式。

## 编码规则

- `HashSaltStrategy` 对完整逻辑标识符字节计算 IEEE CRC32；不做字符串解码、路径归一化或目录深度截断。
- 将无符号 CRC32 值对 16 个桶取模，得到 `0..15` 的桶号。
- 用 2 字节无符号大端序编码桶号。`crc32-bucket-v1` 与编码版本 `1` 是持久格式标识。
- 所有记录类别使用同一 profile。点读和范围扫描先使用同一规则定位桶；range 会按 16 个有序桶扫描并合并逻辑 key。
- `split_keys()` 返回桶 `1..15` 的 2 字节前缀 `0001..000f`。配置中的 table split keys 必须逐项匹配该列表。
- 桶数、编码或输入范围不得在已有表组上静默改变；变更需要独立重编码/迁移设计。盐不包含集群路由 ID，也不证明提交或授权。

空字节串只用于检查 CRC 函数本身的固定向量；具体记录类别是否允许空逻辑标识符由上层记录契约决定。

## 固定向量

| 完整输入字节（hex） | IEEE CRC32 | 桶号 | 盐（hex） |
|---|---:|---:|---|
| 空字节串 | `00000000` | 0 | `0000` |
| `61` | `e8b7be43` | 3 | `0003` |
| `2f612f622f632f` | `639fc949` | 9 | `0009` |
| `00` | `d202ef8d` | 13 | `000d` |
| `ff` | `ff000000` | 0 | `0000` |
| `6100ff` | `9b569788` | 8 | `0008` |
| `2f726f6f74` | `b203698f` | 15 | `000f` |
| `2f726f6f742f` | `04664f0c` | 12 | `000c` |

机器可读的 profile 示例位于 [`config/examples/m0/salt-profile.json`](../../config/examples/m0/salt-profile.json)。公开样本通过 SPI 单元测试验证；它不关闭 B01，也不构成目标环境预分区验收证据。
